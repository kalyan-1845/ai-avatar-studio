**Pro Tip**: For best results, use clear pronunciation in your script. Mouth will animate based on:
- **Vowels (A, E, I, O, U)** → Wide mouth opening
- **Consonants (M, B, P)** → Closed/narrow mouth
- **Sibilants (S, Z, SH)** → Tight, wide lips
- **Rounded sounds (O, U, W)** → Pursed lips

## 📋 Troubleshooting

### Problem: Mouth not opening much
**Solution:**
- Check audio volume (might be too quiet)
- Try louder speech recording
- Verify character is selected
- Try emotion "Happy" to increase mouth movement

### Problem: Video download not working
**Solution:**
✅ **Try different browsers**: Chrome, Firefox, Edge (best support)
✅ **Check settings:**
  - Ensure pop-ups aren't blocked
  - Allow downloads from this site
  - Verify adequate disk space

✅ **Manual workaround:**
- Use **Record** (red) button instead
- Manually stop recording when done
- File downloads to Downloads folder

### Problem: Audio/Video not synced
**Solution:**
- Regenerate audio (click text → "Generate Audio")
- Ensure audio duration matches script length
- Try different TTS voice speed

### Problem: Mouth looks robotic
**Solution:**
- ✅ System now uses 8ms smoothing (much slower)
- Ensures natural, humanized movement
- If still robotic:
  - Try different emotion setting
  - Add more varied text (mix of long/short words)

### Problem: Character looks stiff
**Solution:**
- Enable "Camera Zoom" for dynamic movement
- Use "Dual Character" mode for interaction feel
- Try different backgrounds (adds visual interest)
- Use "Presentation Mode" for focused framing

### Problem: Recording is laggy/choppy
**Solution:**
- Close other apps (frees CPU)
- Lower resolution (800x600 test)
- Use Chrome (fastest rendering)
- Reduce animation complexity

## 🎓 Understanding the Animation System

```
Text Input
    ↓
Phoneme Conversion (text → mouth shapes)
    ↓
Audio Generation (speech)
    ↓
Frequency Analysis (audio → mouth openness)
    ↓
Blending (60% phoneme + 40% audio)
    ↓
Smoothing Filter (8ms exponential moving average)
    ↓
Realistic Mouth Movement
```
